Por qué importa

En B2B el dolor no es el toque del pago — es la confrontación: días de administración cruzando transferencias contra facturas. kotto convierte cada factura en una referencia cobrable, y cada pago entra ya conciliado. De ese cruce, repetido millones de veces, nace el historial de pago entre empresas que ningún banco tiene solo.

Para desarrolladores

El mismo objeto, otra referencia

La API no crece en superficie: crece en contra de qué concilia. Una suscripción, un pedido o una factura — el charge es el mismo y tu integración también.

pago único · concilia contra el pedido
const charge = await kotto.charges.create({
  order_id: "ord_avila_5521",
  amount_usd: "36.50"
});
// webhook:
if (event.type === "charge.succeeded") {
  despacharPedido(event.order_id);
}
B2B · concilia contra la factura
const charge = await kotto.charges.create({
  invoice_id: "inv_F2041",
  amount_usd: "1240.00"
});
// webhook:
if (event.type === "invoice.reconciled") {
  marcarPagada(event.invoice_id);
}

Suscripción, pedido o factura: cambia la referencia, no la tubería.
